# Icons

---

## Icon widget

You can use the **BonsuiIcon** widget that automatically changes the icon color when the dark mode is active.

```dart
BonsuiIcon(
    BonsuiIcons.home,
    size: 30, // Default is 24,
    color: BonsuiDesign.successColor, // Default is primary on ligth mode, white on dark mode
);
```
